ShoeSwap: community shoe marketplace (v1)

Purpose
A web app where members of a run club list used shoes and contact each
other to swap or buy. Payment and delivery happen between users, off-site.

Features
1. Accounts: signup with email verification;
   login/logout; basic profile (name, club, suburb).
2. Listings: brand, model, size (US/EU), condition, mileage (km),
   asking price or "swap", description,  status (available / reserved / gone)
3. Browse and search: filter by brand, model, size, mileage range and
   price range; sort by newest or price; hide gone listings.
4. Contact: an "I'm interested" request that notifies the owner and
   shares contact details between the two users.
5. Permissions: only logged-in members see listings and contact details;
   only owners edit or delete their listings.
6. Safety: report button; admin can remove listings and suspend users;
   terms (the site is not party to transactions) and privacy pages.

Notes:
Just US sizing for V1 
No images for V1 


Out of scope for v1
Payments, shipping, in-app chat, ratings, native mobile app.
